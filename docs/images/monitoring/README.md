# Monitoring diagrams

The three self-contained SVGs are the editable source. Edit their SVG text, labels and vector connectors directly; integration marks are embedded, so there are no standalone vendor icon files or generator to maintain. View the SVG in a browser or SVG editor and inspect layout after changes.

Raster PNG copies are published in the [monitoring Wiki](https://github.com/alanlima/pawlocal/wiki/Monitoring-and-incident-response) for mobile viewing, rather than duplicated in this repository. To refresh those copies, render the edited SVG with an SVG-capable editor/tool and visually check the result before updating the Wiki. Rendering tools are not a project dependency.

Embedded product marks came from official [AWS Architecture Icons (July 2026 package)](https://aws.amazon.com/architecture/icons/), [Grafana](https://raw.githubusercontent.com/grafana/grafana/main/public/img/grafana_icon.svg) and [GitHub](https://github.com/logos), retrieved 23 October 2026. Product marks remain their owners' property; follow the linked usage guidance. The diagrams describe proposed integrations and do not imply sponsorship.
